- [`src/ThreeDCard.tsx`](src/ThreeDCard.tsx)

## Como instalar

1. **Instale as dependências**

   ```bash
   npm install motion clsx tailwind-merge
   ```

2. **Crie src/components/ThreeDCard.tsx** Copie o conteúdo de `src/ThreeDCard.tsx` deste repositório.
3. **Garante que @/lib/utils.ts tem o helper cn**
4. **Usa <CardContainer><CardBody><CardItem translateZ='50'>...</CardItem></CardBody></CardContainer>**
